# MIG Healthcare website

Static site for mighealthcare.com, deployed on Vercel. No build step.

- `assets/site.js`: site scripts and the contact form setting (`WEB3FORMS_KEY`)
- `vercel.json`: clean URLs and redirects (old Sonaris addresses, `/login` to the Partner Portal)
- `_redirects` / `_headers`: the same rules for Cloudflare Pages, if ever used
